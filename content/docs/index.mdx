# Bienvenido a Image Manager

Image Manager es un gestor avanzado de imágenes diseñado para fotógrafos, diseñadores y creadores de contenido que necesitan organizar grandes colecciones de media.

## Características Principales

### 🗂️ **Organización Inteligente**

- Gestión de carpetas jerárquicas
- Etiquetado automático y manual
- Búsqueda avanzada por metadatos
- Filtrado por tipo de archivo y propiedades

### 🖼️ **Visualización Avanzada**

- Vista en miniatura optimizada
- Previsualización de imágenes en alta resolución
- Soporte para múltiples formatos (JPG, PNG, WebP, etc.)
- Vista de cuadrícula virtualizada para rendimiento

### 🏷️ **Sistema de Metadatos**

- Extracción automática de EXIF
- Gestión de tags personalizados
- Información de ubicación y fecha
- Análisis de contenido con IA

### 🔍 **Búsqueda Potente**

- Búsqueda por texto en metadatos
- Filtros avanzados por fecha, ubicación, cámara
- Búsqueda por contenido visual
- Guardado de búsquedas favoritas

## Empezando

Para comenzar a usar Image Manager:

1. **Configura tus directorios**: Ve a configuración y especifica las carpetas donde tienes tus imágenes
2. **Importa tu colección**: El sistema escaneará automáticamente tus archivos
3. **Organiza con tags**: Agrega etiquetas para categorizar tu contenido
4. **Explora y busca**: Usa las herramientas de búsqueda para encontrar exactamente lo que necesitas

## Navegación

- **📁 Carpetas**: Explora tu estructura de directorios
- **🖼️ Todas las Imágenes**: Vista completa de tu colección
- **🏷️ Tags**: Gestiona y navega por etiquetas
- **⭐ Favoritos**: Accede rápido a contenido marcado
- **🔍 Búsqueda**: Herramientas de búsqueda avanzada

¡Disfruta organizando tu contenido visual con Image Manager!
