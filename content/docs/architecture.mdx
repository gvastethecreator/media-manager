# Arquitectura del Proyecto

Esta sección describe la arquitectura actual del monorepo:

- Frontend: React 19, Vite, Zustand, TanStack Query
- Backend: Express sobre Bun con HMR
- ORM: Drizzle sobre SQLite/Turso
- E2E: Playwright
- Desktop: Tauri (no tocar salvo features específicas)

Estructura de carpetas clave y convenciones se documentan en subsecciones.
