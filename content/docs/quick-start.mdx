# Guía de Inicio Rápido

Esta guía te ayudará a configurar Image Manager y comenzar a organizar tu colección de imágenes.

## Requisitos del Sistema

- **Sistema Operativo**: Windows 10/11, macOS 10.14+, Linux Ubuntu 18.04+
- **RAM**: Mínimo 4GB, recomendado 8GB+
- **Espacio en Disco**: Al menos 1GB para la aplicación y base de datos
- **Navegador**: Chrome 90+, Firefox 88+, Safari 14+ (para versión web)

## Primera Configuración

### 1. Configura los Directorios de Imagen

Ve a **⚙️ Configuración** → **Directorios** y agrega las carpetas donde tienes tus imágenes:

1. Haz clic en "Agregar Directorio"
2. Selecciona la carpeta raíz de tus imágenes
3. Elige si quieres incluir subcarpetas automáticamente
4. Guarda la configuración

### 2. Primera Indexación

Una vez configurados los directorios:

1. El sistema iniciará el escaneo automáticamente
2. Puedes ver el progreso en la barra de estado
3. La primera indexación puede tomar varios minutos dependiendo del tamaño de tu colección

### 3. Configuración Básica

Personaliza la experiencia según tus necesidades:

- **Tema**: Claro, oscuro o automático según el sistema
- **Idioma**: Español, inglés y otros idiomas soportados  
- **Calidad de Miniaturas**: Ajusta según tu hardware y preferencias

## Navegación Básica

### Panel de Navegación (Izquierda)

- **📁 Carpetas**: Estructura de directorios de tus imágenes
- **🖼️ Vistas**: Diferentes formas de ver tu contenido
  - *Todas las Imágenes*: Vista completa
  - *Favoritos*: Contenido marcado como favorito  
  - *Recientes*: Archivos agregados recientemente
- **🏷️ Organización**: Herramientas de categorización
  - *Tags*: Etiquetas personalizadas
  - *Álbumes*: Colecciones temáticas
  - *Colecciones*: Agrupaciones avanzadas

### Área Principal (Centro)

Aquí se muestra el contenido seleccionado:

- **Vista de Cuadrícula**: Miniaturas organizadas en rejilla
- **Vista de Lista**: Información detallada en formato tabla
- **Vista de Mosaico**: Presentación estilo magazine

### Panel de Detalles (Derecha)

Información detallada del elemento seleccionado:

- **Metadatos EXIF**: Información de cámara y configuración
- **Propiedades**: Tamaño, formato, fecha de creación
- **Tags**: Etiquetas asignadas (editable)
- **Ubicación**: Datos GPS si están disponibles

## Operaciones Básicas

### Agregar Tags

1. Selecciona una o varias imágenes
2. En el panel derecho, haz clic en "Agregar Tag"  
3. Escribe el nombre del tag o selecciona uno existente
4. Los tags se guardan automáticamente

### Crear Álbumes

1. Ve a **🗂️ Álbumes** en la navegación
2. Haz clic en "Nuevo Álbum"
3. Dale un nombre y descripción
4. Arrastra imágenes desde la vista principal al álbum

### Búsqueda Rápida

Usa la barra de búsqueda en la parte superior:

- **Búsqueda por nombre**: Escribe parte del nombre del archivo
- **Búsqueda por tag**: Usa `tag:naturaleza` para buscar por etiquetas  
- **Búsqueda por fecha**: `año:2023` o `mes:diciembre`
- **Combinaciones**: `tag:viaje año:2023`

## Consejos Útiles

### 🚀 Rendimiento
- Mantén las carpetas organizadas para búsquedas más rápidas
- Usa tags descriptivos para facilitar la búsqueda
- La indexación se ejecuta automáticamente cuando detecta cambios

### 🔧 Personalización  
- Configura atajos de teclado en Configuración → Atajos
- Personaliza la vista de cuadrícula ajustando el tamaño de miniaturas
- Activa notificaciones para estar al tanto de la indexación

### 🔍 Búsqueda Avanzada
- Usa comillas para búsquedas exactas: `"foto de familia"`
- Combina filtros: `tag:naturaleza tipo:jpg tamaño:>5MB`
- Guarda búsquedas frecuentes como filtros favoritos

## Próximos Pasos

Una vez que tengas lo básico configurado:

1. **Explora las vistas avanzadas**: Prueba diferentes formas de visualizar tu contenido
2. **Configura workflows**: Automatiza tareas repetitivas con reglas personalizadas
3. **Integra con otras herramientas**: Conecta Image Manager con tu flujo de trabajo de edición
4. **Haz backup de tu configuración**: Exporta tu configuración y base de datos regularmente
