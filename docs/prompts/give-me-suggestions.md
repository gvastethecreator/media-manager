## Prompts para Solicitar Sugerencias

Este conjunto de prompts está diseñado para obtener recomendaciones y sugerencias de mejora en diferentes aspectos del proyecto. Son útiles para identificar oportunidades de optimización y evolución del sistema.

### Mejoras de Arquitectura

Estos prompts ayudan a identificar posibles mejoras en la arquitectura del sistema.

#### Estructura del Proyecto

```
Analiza la estructura actual del proyecto y sugiere mejoras en la organización de directorios, separación de responsabilidades y patrones arquitectónicos. Considera la escalabilidad y mantenibilidad a largo plazo.
```

#### Patrones de Diseño

```
Evalúa los patrones de diseño utilizados actualmente y recomienda mejoras o nuevos patrones que podrían beneficiar al proyecto. Considera la complejidad actual y futura del sistema.
```

#### Gestión de Estado

```
Analiza la implementación actual de Zustand y sugiere mejoras en la estructura de stores, patrones de actualización y optimización de rendimiento. Considera la escalabilidad del estado global.
```

#### Arquitectura de Servicios

```
Evalúa la arquitectura de servicios actual y propón mejoras en la separación de responsabilidades, comunicación entre servicios y manejo de dependencias.
```

#### Manejo de Datos

```
Analiza el flujo de datos actual y sugiere mejoras en la estructura de la base de datos, estrategias de caché y optimización de consultas.
```

#### Seguridad

```
Evalúa la arquitectura de seguridad actual y propón mejoras en autenticación, autorización, protección de datos y prácticas de seguridad.
```

#### Escalabilidad

```
Analiza los puntos de escalabilidad actuales y sugiere mejoras para manejar mayor carga, más usuarios y más datos de manera eficiente.
```

#### Integración

```
Evalúa las integraciones actuales y propón mejoras en la comunicación entre sistemas, manejo de APIs y sincronización de datos.
```

### Mejoras de UI/UX

Estos prompts se centran en sugerencias para mejorar la experiencia del usuario.

#### Diseño Visual

```
Analiza el diseño visual actual y sugiere mejoras en la consistencia, estética y usabilidad. Considera las últimas tendencias y mejores prácticas de diseño.
```

#### Interacción

```
Evalúa los patrones de interacción actuales y propón mejoras en la respuesta a usuarios, feedback visual y flujos de trabajo.
```

#### Accesibilidad

```
Analiza la accesibilidad actual y sugiere mejoras para hacer la aplicación más inclusiva y compatible con diferentes necesidades de usuarios.
```

#### Responsive Design

```
Evalúa el diseño responsive actual y propón mejoras para diferentes dispositivos, orientaciones y tamaños de pantalla.
```

#### Performance Percibida

```
Analiza la percepción de rendimiento actual y sugiere mejoras en tiempos de carga, feedback visual y estados de transición.
```

#### Navegación

```
Evalúa la estructura de navegación actual y propón mejoras en la organización, descubrimiento y flujo entre diferentes secciones.
```

#### Formularios

```
Analiza los formularios actuales y sugiere mejoras en validación, feedback de errores y experiencia de entrada de datos.
```

#### Visualización de Datos

```
Evalúa la presentación actual de datos y propón mejoras en la visualización, organización y comprensión de la información.
```

```

#### Rendimiento Backend

```

```

#### Optimización de Assets

```
Analiza la gestión actual de assets y sugiere mejoras en carga, optimización y estrategias de caché.
```

#### Optimización de Base de Datos

```

```

#### Caching

```

```

#### Lazy Loading

#### Bundle Size

#### Monitoreo

```
