## Prompts para Creación de Roadmap

Este conjunto de prompts está diseñado para ayudar en la planificación y creación de roadmaps detallados del proyecto. Son útiles para definir la dirección estratégica, priorizar características y establecer hitos claros para el desarrollo.

### Análisis de Estado Actual

Estos prompts ayudan a evaluar el estado actual del proyecto para establecer una base sólida para la planificación.

#### Evaluación de Características

```
Realiza un análisis detallado del estado actual de las características implementadas, incluyendo su completitud, estabilidad y áreas de mejora. Considera el feedback de usuarios y los reportes de errores existentes.
```

#### Análisis de Arquitectura

```
Evalúa la arquitectura actual del sistema, identificando fortalezas, debilidades y áreas que necesitan refactorización o mejoras. Considera la escalabilidad y mantenibilidad a largo plazo.
```

#### Revisión de Dependencias

```
Analiza las dependencias actuales del proyecto, su estado de actualización, posibles vulnerabilidades y oportunidades de optimización. Considera la compatibilidad futura y el soporte a largo plazo.
```

#### Evaluación de Rendimiento

```
Realiza un análisis completo del rendimiento actual, identificando cuellos de botella, problemas de memoria y oportunidades de optimización. Incluye métricas clave y comparativas con benchmarks.
```

#### Análisis de UX

```
Evalúa la experiencia de usuario actual, incluyendo patrones de uso, puntos de fricción y feedback de usuarios. Considera la accesibilidad y la usabilidad en diferentes dispositivos.
```

#### Revisión de Código

```
Analiza la calidad del código actual, incluyendo cobertura de tests, documentación, y adherencia a estándares. Identifica áreas que necesitan mejora o refactorización.
```

#### Evaluación de Seguridad

```
Realiza un análisis de seguridad del sistema actual, identificando vulnerabilidades potenciales y áreas que requieren mejoras en la protección de datos y privacidad.
```

#### Análisis de Infraestructura

```
Evalúa la infraestructura actual, incluyendo el almacenamiento, procesamiento y distribución de recursos. Considera la escalabilidad y eficiencia del sistema.
```

### Planificación de Características

Estos prompts ayudan a definir y priorizar las características futuras del proyecto.

#### Características Core

```
Define las características fundamentales que necesitan ser implementadas o mejoradas en el próximo ciclo, incluyendo estimaciones de tiempo, recursos necesarios y dependencias técnicas.
```

#### Mejoras de UX

```
Planifica las mejoras en la experiencia de usuario, incluyendo rediseños de interfaz, optimizaciones de flujos de trabajo y nuevas interacciones. Prioriza basándote en el impacto al usuario.
```

#### Optimizaciones Técnicas

```
Define las optimizaciones técnicas necesarias, incluyendo mejoras de rendimiento, refactorizaciones y actualizaciones de arquitectura. Considera el impacto en el desarrollo futuro.
```

#### Características Avanzadas

```
Planifica la implementación de características avanzadas como ML, procesamiento automático y análisis de datos. Considera la viabilidad técnica y los recursos necesarios.
```

#### Integraciones

```
Define las integraciones necesarias con servicios externos o sistemas internos, incluyendo APIs, protocolos y requisitos de seguridad. Considera la escalabilidad y mantenimiento.
```

#### Herramientas de Desarrollo

```
Planifica mejoras en las herramientas y flujos de desarrollo, incluyendo CI/CD, testing y documentación. Considera la eficiencia del equipo y la calidad del código.
```

#### Seguridad y Privacidad

```
Define las mejoras necesarias en seguridad y privacidad, incluyendo encriptación, autenticación y protección de datos. Considera regulaciones y mejores prácticas.
```

#### Escalabilidad

```
Planifica las mejoras necesarias para la escalabilidad del sistema, incluyendo optimizaciones de base de datos, caché y procesamiento distribuido.
```

### Definición de Hitos

Estos prompts ayudan a establecer hitos claros y medibles para el proyecto.

#### Hitos Técnicos

```
Define hitos técnicos específicos y medibles, incluyendo mejoras de rendimiento, cobertura de tests y reducción de deuda técnica. Establece criterios de éxito claros.
```

#### Hitos de Producto

```
Establece hitos relacionados con características del producto, incluyendo lanzamientos de funcionalidades, mejoras de UX y feedback de usuarios. Define métricas de adopción y satisfacción.
```

#### Hitos de Calidad

```
Define hitos relacionados con la calidad del código, documentación y pruebas. Establece estándares y métricas para medir el progreso.
```

#### Hitos de Rendimiento

```
Establece objetivos específicos de rendimiento, incluyendo tiempos de carga, uso de recursos y eficiencia. Define benchmarks y métodos de medición.
```

#### Hitos de Seguridad

```
Define hitos relacionados con mejoras de seguridad, auditorías y cumplimiento de estándares. Establece criterios de verificación y validación.
```

#### Hitos de Escalabilidad

```
Establece objetivos relacionados con la capacidad y escalabilidad del sistema, incluyendo métricas de rendimiento bajo carga y eficiencia de recursos.
```

#### Hitos de Adopción

```
Define objetivos relacionados con la adopción de nuevas características, satisfacción del usuario y métricas de engagement. Establece KPIs claros.
```

#### Hitos de Mantenibilidad

```
Establece objetivos relacionados con la mantenibilidad del código, documentación y procesos de desarrollo. Define métricas de calidad y eficiencia.
```

### Planificación de Recursos

Estos prompts ayudan a planificar los recursos necesarios para ejecutar el roadmap.

#### Recursos Técnicos

```
Define los recursos técnicos necesarios para implementar el roadmap, incluyendo infraestructura, herramientas y servicios externos. Considera costos y escalabilidad.
```

#### Recursos Humanos

```
Planifica los recursos humanos necesarios, incluyendo roles, habilidades requeridas y estructura del equipo. Considera la capacitación y el crecimiento del equipo.
```

#### Recursos de Tiempo

```
Establece estimaciones detalladas de tiempo para cada fase del roadmap, incluyendo desarrollo, testing y despliegue. Considera dependencias y riesgos.
```

#### Recursos de Conocimiento

```
Define los recursos de conocimiento necesarios, incluyendo documentación, capacitación y transferencia de conocimiento. Planifica la gestión del conocimiento.
```

#### Recursos de Calidad

```
Planifica los recursos necesarios para mantener y mejorar la calidad, incluyendo herramientas de testing, revisión de código y monitoreo.
```

#### Recursos de Seguridad

```
Define los recursos necesarios para implementar y mantener las medidas de seguridad, incluyendo herramientas, auditorías y certificaciones.
```

#### Recursos de Monitoreo

```
Planifica los recursos necesarios para el monitoreo y análisis del sistema, incluyendo herramientas de logging, métricas y alertas.
```

#### Recursos de Soporte

```
Define los recursos necesarios para el soporte y mantenimiento continuo, incluyendo documentación, herramientas de diagnóstico y procesos de respuesta.
```

### Gestión de Riesgos

Estos prompts ayudan a identificar y planificar la mitigación de riesgos potenciales.

#### Riesgos Técnicos

```
Identifica y evalúa los riesgos técnicos potenciales en el roadmap, incluyendo dependencias, limitaciones técnicas y deuda técnica. Desarrolla estrategias de mitigación.
```

#### Riesgos de Recursos

```
Analiza los riesgos relacionados con la disponibilidad y gestión de recursos, incluyendo personal, tiempo y presupuesto. Planifica contingencias.
```

#### Riesgos de Adopción

```
Evalúa los riesgos relacionados con la adopción de nuevas características y cambios, incluyendo resistencia al cambio y curva de aprendizaje. Desarrolla estrategias de gestión del cambio.
```

#### Riesgos de Seguridad

```
Identifica y evalúa los riesgos de seguridad potenciales, incluyendo vulnerabilidades, amenazas y cumplimiento normativo. Desarrolla planes de mitigación.
```

#### Riesgos de Rendimiento

```
Analiza los riesgos relacionados con el rendimiento y la escalabilidad, incluyendo cuellos de botella potenciales y límites del sistema. Planifica optimizaciones.
```

#### Riesgos de Integración

```
Evalúa los riesgos relacionados con la integración de nuevos sistemas y características, incluyendo compatibilidad y dependencias. Desarrolla estrategias de prueba.
```

#### Riesgos de Calidad

```
Identifica los riesgos relacionados con la calidad del código y producto, incluyendo deuda técnica y mantenibilidad. Planifica mejoras continuas.
```

#### Riesgos de Mercado

```
Analiza los riesgos relacionados con cambios en el mercado, tecnología y requisitos de usuarios. Desarrolla estrategias de adaptación.
```
