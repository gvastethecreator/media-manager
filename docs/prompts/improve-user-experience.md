## Prompts para Mejora de Experiencia de Usuario

Este conjunto de prompts está diseñado para identificar oportunidades y mejorar la experiencia de usuario en diferentes aspectos de la aplicación. Son útiles para crear una interfaz más intuitiva, accesible y agradable.

### Interacciones y Feedback

Estos prompts se centran en mejorar la interactividad y retroalimentación al usuario.

#### Micro-interacciones

```
Implementa micro-interacciones significativas en [componente]. Añade animaciones sutiles para acciones del usuario, feedback visual inmediato y transiciones fluidas. Asegura que cada interacción mejore la comprensión y engagement.
```

#### Estados de Carga

```
Mejora la experiencia durante estados de carga en [característica]. Implementa skeletons atractivos, loading states progresivos y feedback visual del progreso. Mantén al usuario informado y entretenido durante la espera.
```

#### Feedback de Acciones

```
Optimiza el feedback visual y auditivo para acciones del usuario en [componente]. Implementa confirmaciones claras, mensajes de éxito/error contextuales y notificaciones no intrusivas. Asegura que el usuario siempre sepa el resultado de sus acciones.
```

#### Gestos y Controles

```
Mejora los controles y gestos en [componente]. Implementa interacciones naturales, soporte para touch/mouse/teclado y comportamientos intuitivos. Optimiza para diferentes dispositivos y métodos de entrada.
```

#### Estados Vacíos

```
Diseña estados vacíos significativos para [vista/componente]. Implementa ilustraciones atractivas, mensajes útiles y acciones claras. Guía al usuario sobre cómo comenzar o qué hacer siguiente.
```

#### Transiciones de Estado

```
Optimiza las transiciones entre estados en [componente]. Implementa animaciones suaves entre cambios de estado, mantén contexto visual y asegura continuidad en la experiencia.
```

#### Prevención de Errores

```
Mejora la prevención de errores en [formulario/acción]. Implementa validación en tiempo real, sugerencias proactivas y confirmaciones para acciones importantes. Ayuda al usuario a evitar errores antes de que ocurran.
```

#### Recuperación de Errores

```
Optimiza la experiencia de recuperación de errores en [característica]. Implementa mensajes claros, sugerencias de solución y opciones de recuperación. Mantén al usuario informado y empoderado para resolver problemas.
```

### Navegación y Estructura

Estos prompts se centran en mejorar la navegación y organización del contenido.

#### Jerarquía Visual

```
Mejora la jerarquía visual en [vista]. Optimiza tipografía, espaciado y contraste para guiar la atención del usuario. Implementa una estructura clara y escaneable del contenido.
```

#### Navegación Principal

```
Optimiza la navegación principal de la aplicación. Implementa estructura clara, indicadores de ubicación y accesos rápidos a funciones principales. Facilita el descubrimiento y acceso a diferentes secciones.
```

#### Breadcrumbs y Contexto

```
Mejora los indicadores de contexto en [sección]. Implementa breadcrumbs claros, títulos descriptivos y referencias visuales de ubicación. Ayuda al usuario a entender dónde está y cómo llegó allí.
```

#### Búsqueda y Filtros

```
Optimiza la experiencia de búsqueda y filtrado en [vista]. Implementa búsqueda predictiva, filtros intuitivos y resultados relevantes. Facilita la encontrabilidad de contenido.
```

#### Navegación Secundaria

```
Mejora la navegación secundaria en [sección]. Implementa menús contextuales, shortcuts y enlaces relacionados. Facilita la exploración y descubrimiento de funcionalidades.
```

#### Mobile Navigation

```
Optimiza la navegación móvil de la aplicación. Implementa patrones mobile-first, gestos intuitivos y menús adaptables. Asegura una experiencia fluida en dispositivos móviles.
```

#### Wayfinding

```
Mejora las señales de orientación en [sección]. Implementa señales visuales, landmarks y puntos de referencia claros. Ayuda al usuario a orientarse y navegar con confianza.
```

#### Quick Actions

```
Optimiza el acceso a acciones rápidas en [vista]. Implementa shortcuts, menús contextuales y accesos directos a funciones frecuentes. Mejora la eficiencia de uso.
```

### Personalización y Adaptabilidad

Estos prompts se centran en mejorar la personalización y adaptabilidad de la interfaz.

#### Preferencias de Usuario

```
Implementa opciones de personalización en [característica]. Permite ajustar configuraciones visuales, comportamientos y preferencias. Guarda y aplica preferencias de manera consistente.
```

#### Temas y Apariencia

```
Mejora el sistema de temas de la aplicación. Implementa cambios fluidos entre temas, personalización de colores y adaptación a preferencias del sistema. Asegura consistencia visual en diferentes modos.
```

#### Responsive Layout

```
Optimiza layouts responsivos en [vista]. Implementa diseños adaptables, reorganización de contenido y optimización para diferentes tamaños de pantalla. Mantén la usabilidad en todos los dispositivos.
```

#### Accesibilidad Visual

```
Mejora la accesibilidad visual en [componente]. Implementa contraste adaptable, tamaños de texto ajustables y soporte para lectores de pantalla. Asegura que la interfaz sea usable para todos.
```

#### Contenido Adaptativo

```
Implementa contenido adaptativo en [vista]. Ajusta presentación según contexto, preferencias y comportamiento del usuario. Personaliza la experiencia basada en patrones de uso.
```

#### Estado Persistente

```
Mejora la persistencia de estado en [característica]. Guarda y restaura estados de interfaz, preferencias y últimas acciones. Mantén continuidad en la experiencia del usuario.
```

#### Customización de Workspace

```
Implementa opciones de customización del espacio de trabajo. Permite reorganizar elementos, ajustar layouts y guardar configuraciones personalizadas. Empodera al usuario para optimizar su flujo de trabajo.
```

#### Adaptación Contextual

```
Mejora la adaptación contextual de [componente]. Ajusta comportamiento y presentación según contexto de uso, dispositivo y preferencias. Optimiza la experiencia para diferentes escenarios.
```

### Onboarding y Guía

Estos prompts se centran en mejorar la experiencia de nuevos usuarios.

#### Primera Experiencia

```
Optimiza la primera experiencia de usuario en la aplicación. Implementa welcome tour, highlights de características clave y setup inicial guiado. Crea una primera impresión positiva y clara.
```

#### Tooltips y Ayuda

```
Mejora el sistema de ayuda contextual en [característica]. Implementa tooltips informativos, guías paso a paso y documentación accesible. Ayuda al usuario a aprender y dominar funcionalidades.
```

#### Feature Discovery

```
Implementa descubrimiento progresivo de características en [sección]. Introduce funcionalidades gradualmente, destaca nuevas features y guía en el aprendizaje. Evita la sobrecarga de información.
```

#### Mensajes Contextuales

```
Optimiza mensajes y guías contextuales en [componente]. Implementa hints útiles, sugerencias proactivas y ayuda relevante al contexto. Mejora la comprensión y uso efectivo.
```

#### Progress Tracking

```
Mejora el tracking de progreso en [característica]. Implementa indicadores de avance, celebración de hitos y feedback de mejora. Motiva y guía al usuario en su journey.
```

#### Interactive Tutorials

```
Implementa tutoriales interactivos para [característica]. Crea guías paso a paso, ejercicios prácticos y feedback inmediato. Facilita el aprendizaje a través de la práctica.
```

#### Documentación In-App

```
Mejora la documentación integrada en la aplicación. Implementa búsqueda rápida, ejemplos contextuales y acceso fácil a recursos de ayuda. Facilita el auto-aprendizaje.
```

#### Feedback Loop

```
Optimiza el ciclo de feedback con usuarios en [característica]. Implementa mecanismos de recolección de feedback, sugerencias de mejora y comunicación de updates. Mantén un diálogo continuo con los usuarios.
```
