## Prompts para Mejora de Animaciones

Este conjunto de prompts está diseñado para optimizar y mejorar las animaciones en toda la aplicación. Son útiles para crear una experiencia de usuario más fluida y atractiva, manteniendo el rendimiento y la accesibilidad.

### Animaciones de Interfaz

Estos prompts se centran en mejorar las animaciones básicas de la interfaz de usuario para una mejor experiencia visual.

#### Transiciones de Vista

```
Optimiza las transiciones entre vistas principales de la aplicación, implementando animaciones suaves y contextuales que ayuden a entender el flujo de navegación. Considera el rendimiento y la accesibilidad, incluyendo preferencias de reducción de movimiento.
```

#### Feedback de Interacción

```
Mejora el feedback visual de interacciones como clicks, hovers y selecciones, implementando micro-animaciones sutiles pero efectivas. Asegura que las animaciones sean consistentes y significativas para la experiencia del usuario.
```

#### Estados de Carga

```
Desarrolla animaciones atractivas para estados de carga y procesamiento, incluyendo skeletons, spinners y barras de progreso. Implementa transiciones suaves entre estados y feedback visual claro del progreso.
```

#### Navegación Modal

```
Optimiza las animaciones de apertura, cierre y transición de modales y diálogos, asegurando que sean suaves y contextuales. Implementa gestos y transiciones naturales que mejoren la experiencia de usuario.
```

#### Efectos de Lista

```
Mejora las animaciones de listas y grids, incluyendo ordenamiento, filtrado y actualización de elementos. Implementa transiciones suaves para cambios de estado y reordenamiento.
```

#### Gestos Táctiles

```
Desarrolla animaciones responsivas para gestos táctiles como swipe, pinch y pan, asegurando que sean naturales y fluidas. Considera la física de las animaciones y el feedback visual.
```

#### Notificaciones

```
Implementa animaciones atractivas para el sistema de notificaciones, incluyendo entrada, salida y transiciones entre estados. Asegura que sean visibles pero no intrusivas.
```

#### Tooltips y Popovers

```
Optimiza las animaciones de tooltips y popovers, implementando transiciones suaves y contextuales. Considera la posición y el timing de las animaciones.
```

### Animaciones de Contenido

Estos prompts se enfocan en mejorar las animaciones relacionadas con el contenido principal de la aplicación.

#### Zoom de Imágenes

```
Mejora las animaciones de zoom y pan en el visor de imágenes, implementando transiciones suaves y naturales. Optimiza el rendimiento para imágenes de alta resolución y considera gestos táctiles.
```

#### Transiciones de Galería

```
Desarrolla transiciones fluidas para la navegación en la galería, incluyendo cambios de vista, filtrado y ordenamiento. Implementa animaciones que ayuden a entender los cambios de estado.
```

#### Previsualización

```
Optimiza las animaciones de previsualización de imágenes, implementando transiciones suaves entre thumbnails y vista completa. Considera el rendimiento y la carga progresiva.
```

#### Efectos de Selección

```
Mejora las animaciones de selección de elementos, implementando feedback visual claro y transiciones suaves. Considera selecciones múltiples y estados intermedios.
```

#### Drag and Drop

```
Desarrolla animaciones fluidas para operaciones de arrastrar y soltar, incluyendo feedback visual durante el arrastre y transiciones al soltar. Optimiza para diferentes tipos de contenido.
```

#### Cambios de Estado

```
Implementa animaciones suaves para cambios de estado en elementos de contenido, como favoritos, etiquetas o metadatos. Asegura feedback visual claro y transiciones naturales.
```

#### Cargas Asíncronas

```
Mejora las animaciones durante la carga asíncrona de contenido, implementando transiciones suaves entre estados de carga y contenido final. Optimiza la experiencia de usuario durante la espera.
```

#### Efectos de Hover

```
Desarrolla efectos de hover atractivos y significativos para elementos de contenido, asegurando que sean consistentes y mejoren la experiencia de usuario.
```

### Optimización de Rendimiento

Estos prompts se centran en optimizar el rendimiento de las animaciones para una experiencia fluida.

#### Optimización de Frame Rate

```
Analiza y optimiza el frame rate de las animaciones, identificando y corrigiendo caídas de FPS. Implementa técnicas de optimización como GPU acceleration y will-change.
```

#### Gestión de Recursos

```
Mejora la gestión de recursos durante las animaciones, optimizando el uso de memoria y CPU. Implementa técnicas de cleanup y garbage collection.
```

#### Animaciones Condicionales

```
Desarrolla un sistema para manejar animaciones basadas en las capacidades del dispositivo y preferencias del usuario. Implementa fallbacks y reducción de complejidad cuando sea necesario.
```

#### Batch Updates

```
Optimiza las actualizaciones del DOM durante animaciones múltiples, implementando técnicas de batch processing y virtualización cuando sea apropiado.
```

#### Lazy Loading

```
Mejora la carga diferida de animaciones y recursos relacionados, implementando priorización y precarga inteligente. Optimiza la experiencia inicial del usuario.
```

#### Debugging

```
Implementa herramientas y métricas para debuggear el rendimiento de animaciones, incluyendo timeline recording y performance monitoring.
```

#### Throttling y Debouncing

```
Optimiza el manejo de eventos durante animaciones, implementando técnicas de throttling y debouncing para mejorar el rendimiento.
```

#### Memory Management

```
Mejora la gestión de memoria durante animaciones complejas, implementando técnicas de pooling y reutilización de recursos cuando sea apropiado.
```

### Accesibilidad

Estos prompts se enfocan en asegurar que las animaciones sean accesibles para todos los usuarios.

#### Preferencias de Movimiento

```
Implementa soporte robusto para prefers-reduced-motion, desarrollando alternativas apropiadas para usuarios que prefieren menos movimiento. Asegura una experiencia consistente.
```

#### Timing y Duración

```
Optimiza el timing y duración de las animaciones para diferentes contextos y preferencias de usuario. Implementa controles de velocidad cuando sea apropiado.
```

#### Alternativas No Animadas

```
Desarrolla alternativas no animadas para funcionalidades clave, asegurando que la aplicación sea completamente funcional sin animaciones.
```

#### Feedback Auditivo

```
Implementa feedback auditivo apropiado para complementar animaciones importantes, considerando la accesibilidad y preferencias del usuario.
```

#### Control de Usuario

```
Desarrolla controles que permitan a los usuarios personalizar o deshabilitar animaciones específicas según sus necesidades.
```

#### Documentación

```
Mejora la documentación de las animaciones y sus alternativas accesibles, incluyendo guías para desarrolladores y usuarios.
```

#### Testing

```
Implementa pruebas exhaustivas de accesibilidad para animaciones, incluyendo diferentes dispositivos y tecnologías de asistencia.
```

#### Feedback Visual

```
Optimiza el feedback visual para usuarios que no pueden percibir las animaciones, asegurando que la información importante sea comunicada efectivamente.
```

### Consistencia y Diseño

Estos prompts se centran en mantener la consistencia y calidad del diseño en las animaciones.

#### Sistema de Animación

```
Desarrolla un sistema coherente de animaciones, incluyendo timing functions, duraciones y efectos estándar. Documenta y mantén consistencia en toda la aplicación.
```

#### Tokens de Animación

```
Implementa un sistema de tokens para animaciones, incluyendo variables para timing, easing y otros parámetros comunes. Asegura consistencia y mantenibilidad.
```

#### Guías de Estilo

```
Desarrolla y mantén guías de estilo detalladas para animaciones, incluyendo ejemplos, mejores prácticas y patrones comunes.
```

#### Componentes Animados

```
Crea componentes reutilizables con animaciones integradas, asegurando consistencia y mantenibilidad en toda la aplicación.
```

#### Transiciones Contextuales

```
Implementa un sistema de transiciones que considere el contexto y la jerarquía visual, mejorando la comprensión del usuario.
```

#### Estados Compuestos

```
Desarrolla animaciones para estados compuestos y transiciones complejas, manteniendo la coherencia visual y la claridad.
```

#### Personalización Temática

```
Implementa soporte para personalización de animaciones basada en temas, manteniendo la consistencia visual.
```

#### Documentación Visual

```
Crea documentación visual detallada de las animaciones, incluyendo ejemplos interactivos y guías de implementación.
```
