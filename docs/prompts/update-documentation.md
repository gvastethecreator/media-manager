## Prompts para Actualización de Documentación

Este conjunto de prompts está diseñado para ayudar en la creación, actualización y mejora de la documentación del proyecto. Son útiles para mantener la documentación actualizada, clara y útil para diferentes audiencias.

### Documentación Técnica

Estos prompts se centran en la documentación técnica del proyecto.

#### Arquitectura

```
Actualiza la documentación de arquitectura del proyecto, incluyendo diagramas, descripción de componentes principales, flujos de datos y decisiones de diseño. Asegura que refleje la estructura actual del sistema.
```

#### API

```
Mejora la documentación de la API, incluyendo endpoints, parámetros, respuestas, ejemplos de uso y casos de error. Actualiza según los últimos cambios y mejores prácticas de documentación.
```

#### Base de Datos

```
Actualiza la documentación del esquema de base de datos, incluyendo modelos, relaciones, índices y constraints. Incluye ejemplos de queries comunes y consideraciones de rendimiento.
```

#### Servicios

```
Mejora la documentación de los servicios del sistema, incluyendo responsabilidades, dependencias, configuración y patrones de uso. Actualiza con los últimos cambios y mejoras.
```

#### Componentes

```
Actualiza la documentación de componentes React, incluyendo props, estados, eventos y ejemplos de uso. Incluye consideraciones de rendimiento y accesibilidad.
```

#### Testing

```
Mejora la documentación de testing, incluyendo estrategias, herramientas, configuración y ejemplos. Actualiza con las últimas prácticas y patrones de testing.
```

#### Seguridad

```
Actualiza la documentación de seguridad, incluyendo prácticas, configuraciones, manejo de datos sensibles y consideraciones de privacidad.
```

#### Performance

```
Mejora la documentación de performance, incluyendo estrategias de optimización, métricas clave y herramientas de monitoreo.
```

### Documentación de Desarrollo

Estos prompts se centran en la documentación para desarrolladores.

#### Setup

```
Actualiza la documentación de setup del proyecto, incluyendo requisitos, instalación, configuración y primeros pasos. Asegura que sea clara y actualizada.
```

#### Flujo de Trabajo

```
Mejora la documentación del flujo de trabajo de desarrollo, incluyendo branching, commits, revisiones y deployment. Actualiza según las últimas prácticas del equipo.
```

#### Guías de Estilo

```
Actualiza las guías de estilo de código, incluyendo convenciones, patrones y mejores prácticas. Asegura consistencia con el código actual.
```

#### Debugging

```
Mejora la documentación de debugging, incluyendo herramientas, técnicas y soluciones a problemas comunes. Actualiza con nuevos casos y soluciones.
```

#### Scripts

```
Actualiza la documentación de scripts y herramientas de desarrollo, incluyendo propósito, uso y ejemplos. Mantén actualizada la lista de comandos disponibles.
```

#### Dependencias

```
Mejora la documentación de dependencias del proyecto, incluyendo propósito, versiones y consideraciones especiales. Actualiza con los últimos cambios.
```

#### CI/CD

```
Actualiza la documentación del pipeline de CI/CD, incluyendo etapas, configuración y troubleshooting. Mantén actualizados los procesos de automatización.
```

#### Contribución

```
Mejora las guías de contribución, incluyendo proceso, estándares y expectativas. Actualiza para facilitar la incorporación de nuevos contribuidores.
```

### Documentación de Usuario

Estos prompts se centran en la documentación para usuarios finales.

#### Guías de Usuario

```
Actualiza las guías de usuario, incluyendo funcionalidades principales, flujos de trabajo y mejores prácticas. Asegura que sea clara y accesible.
```

#### Tutoriales

```
Mejora los tutoriales existentes y crea nuevos según sea necesario, cubriendo casos de uso comunes y características avanzadas. Incluye ejemplos prácticos.
```

#### FAQ

```
Actualiza la sección de preguntas frecuentes, incluyendo problemas comunes, soluciones y tips. Mantén actualizada según el feedback de usuarios.
```

#### Troubleshooting

```
Mejora la documentación de resolución de problemas, incluyendo casos comunes, diagnóstico y soluciones. Actualiza con nuevos problemas y soluciones.
```

#### Características

```
Actualiza la documentación de características del producto, incluyendo descripciones, configuraciones y casos de uso. Mantén actualizada con nuevas funcionalidades.
```

#### Cambios

```
Mejora la documentación de cambios y actualizaciones, incluyendo nuevas características, mejoras y correcciones. Mantén un registro claro de cambios.
```

#### Migración

```
Actualiza las guías de migración entre versiones, incluyendo cambios breaking, pasos necesarios y consideraciones especiales.
```

#### Integración

```
Mejora la documentación de integración con otros sistemas, incluyendo requisitos, configuración y ejemplos de uso.
```

### Documentación de Mantenimiento

Estos prompts se centran en la documentación para mantenimiento del sistema.

#### Monitoreo

```
Actualiza la documentación de monitoreo del sistema, incluyendo métricas, alertas y procedimientos de respuesta. Mantén actualizadas las prácticas de observabilidad.
```

#### Backup

```
Mejora la documentación de procesos de backup y recuperación, incluyendo procedimientos, verificación y restauración. Actualiza según las últimas prácticas.
```

#### Escalabilidad

```
Actualiza la documentación de escalabilidad, incluyendo límites, estrategias y consideraciones de crecimiento. Mantén actualizadas las recomendaciones.
```

#### Logs

```
Mejora la documentación del sistema de logging, incluyendo niveles, formato y retención. Actualiza las prácticas de gestión de logs.
```

#### Incidentes

```
Actualiza la documentación de manejo de incidentes, incluyendo procedimientos, comunicación y post-mortems. Mantén actualizados los protocolos.
```

#### Mantenimiento

```
Mejora la documentación de tareas de mantenimiento rutinario, incluyendo checklist, frecuencia y procedimientos. Actualiza según las necesidades actuales.
```

#### Seguridad

```
Actualiza la documentación de procedimientos de seguridad, incluyendo auditorías, actualizaciones y respuesta a incidentes. Mantén actualizadas las prácticas.
```

#### Optimización

```
Mejora la documentación de procesos de optimización, incluyendo áreas clave, herramientas y métricas. Actualiza con nuevas técnicas y mejores prácticas.
```
