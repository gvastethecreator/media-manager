# Documentación del proyecto

Este directorio reúne notas técnicas y guías de arquitectura.

- `components-file-browser.md` describe la estructura del FileBrowser.
- `entities.md` explica las entidades principales y sus relaciones.
- `transformers.md` detalla la capa de transformación de datos.
- `server-actions.md` describe la colección de Server Actions por entidad.
- `services.md` resume la capa de servicios y su relación con las Server Actions.
- `utils-lib.md` explica las utilidades de `src/utils` y la biblioteca `src/lib`.
- `contributing.md` guía el flujo de trabajo para nuevos colaboradores.
- `../src/tests/README.md` explica la estrategia de testing y mockeo.
- `../FOLDER-FIX-SUMMARY.md` resume la corrección del módulo de carpetas.
- `../RESUMEN-VERIFICACION-TARJETAS.md` documenta la depuración de los tests de tarjetas.
